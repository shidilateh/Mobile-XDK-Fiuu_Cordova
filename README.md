# Introduction

This is the functional Fiuu Cordova demo.

This demo provides an integrated Fiuu payment module that contains a cordova plugin.

## Notes/ Prerequisite

    - Cordova SDK Version: 12.0.0 ++
    
    - Node.js Version: 20.14.0 ++
    
    - Minimum Android target version: Android 4.4
    
    - Minimum iOS target version: 16.0
